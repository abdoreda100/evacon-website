# إيفاكون | الموقع العقاري الرسمي التجريبي — EVACON

المشروع ده نموذج جاهز للتشغيل والتعديل، لشركة **Real Estate Brokerage**. هوية «إيفاكون» تعتمد على الشعار المقدم من الشركة، وأسعار ووحدات ورسوم العقارات للتوضيح فقط وليست عروضًا حقيقية.

## الموجود داخل الموقع

- صفحة رئيسية حديثة عربية من اليمين للشمال (RTL)، ومتجاوبة مع التليفونات والتابلت والكمبيوتر.
- أقسام تعريف الشركة ورؤيتها ورسالتها وهدفها، وأسباب اختيارها وخطوات العمل.
- 6 وحدات تجريبية بأسعار ومساحات وغرف ومواقع، وصفحة منفصلة **لكل وحدة**.
- البحث والتصفية حسب المنطقة ونوع العقار والميزانية، مع فلترة سريعة حسب النوع.
- طلب تواصل/استشارة وتحديد الوحدة والمنطقة والميزانية وموعد معاينة مفضل.
- حفظ طلبات العملاء في السيرفر برقم مرجعي، ولوحة إدارة محمية تعرضها وتصدرها CSV.
- صفحة سياسة خصوصية نموذجية، وعناوين/وصف Meta مستقل لكل وحدة.
- صفر مكتبات JavaScript أو خادم خارجية مطلوبة للتشغيل؛ Node.js فقط. الصور ملفات SVG محلية توضيحية، والخط الإنجليزي/العربي المحسّن يتحمل من Google Fonts إذا الإنترنت متاح (مع خط احتياطي).

قبل الإطلاق، وبعد وضع بيانات الشركة والعقارات الحقيقية ومراجعة سياسة الخصوصية:

1. استبدل الديمو والصور والأسعار وأضف رقم الهاتف/البريد/العنوان الحقيقيين إن وُجدوا.
2. أزل علامات الـDemo، واكتب Meta Titles/Descriptions حقيقية.
3. غيّر `robots.txt` إلى السماح بالزحف مع منع مسارات الإدارة، وأزل `noindex` من الصفحات اللي عايز تفهرسها. **لازم الأمرين معًا**؛ إزالة أحدهما وحده غير كافية.
4. أنشئ `sitemap.xml` بالروابط النهائية من قائمة `data/site-routes.txt` بعد إضافة الدومين، وقدّمها في Google Search Console.
5. جهّز صفحات مناطق/خدمات بمحتوى فريد لو محتاج تستهدف كلمات زي «شقق للبيع في التجمع الخامس»، واستخدم صورًا ومواصفات أصلية.
6. اربط Google Analytics 4 / Search Console بعد ضبط سياسة خصوصية وإشعار تقنيات التتبع المناسبين.
7. استخدم Schema مناسب للـReal Estate Agent / الـProperty فقط ببيانات حقيقية ومحدثة.

## ملفات المشروع

| الملف / المجلد | وظيفته |
| --- | --- |
| `index.html` | الصفحة الرئيسية المولّدة |
| `home.template.html` | قالب الصفحة الرئيسية القابل للتعديل |
| `properties/*.html` | صفحات العقارات المولّدة |
| `assets/styles.css` | تصميم الموقع |
| `assets/app.js` | التفاعل، الفلترة، وإرسال الفورم |
| `assets/*.svg` | رسوم معمارية توضيحية واللوجو والأيقونات |
| `data/properties.json` | قائمة الوحدات وأسعارها |
| `server.mjs` | السيرفر وواجهة API للحفظ ولوحة الإدارة |
| `admin.html` | صفحة طلبات العملاء |
| `privacy.html` | صفحة سياسة الخصوصية النموذجية |
| `build.py` | توليد الصفحات من JSON |
| `make_assets.py` | إعادة توليد الرسوم التوضيحية، إذا احتجت |

**النسخة دي Prototype قابل للتشغيل، مش إطلاق إنتاج نهائي.** لازم تبديل البيانات التجريبية، ربط الاستضافة والدومين، واختبار الأمان والخصوصية قبل استقبال بيانات عملاء حقيقية.

## الهوية الرسمية المضافة

- الشعار الأصلي المقدم محفوظ بشفافيته في `assets/evacon-logo.png`.
- أيقونة الشعار مقصوصة فقط في `assets/evacon-mark.png` للـHeader وبعض الصفحات الداخلية، ويظهر الشعار الكامل في Footer الصفحة الرئيسية، و`assets/evacon-favicon.png` للمتصفح.
- اعتمدنا ألوان الشعار الأحمر والأسود والأبيض، واسم EVACON / إيفاكون، وشعاره المكتوب «ابتكر، اصنع الفرق» / «We Innovate to Make a Difference».
- اسم الشركة وشعارها هنا حقيقيان بناءً على الملف المرسل؛ **الوحدات والأسعار والموقع الجغرافي المفترض لا تزال تجريبية**.
