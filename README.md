# إيفاكون | الموقع العقاري الرسمي التجريبي — EVACON

المشروع ده نموذج جاهز للتشغيل والتعديل، لشركة **Real Estate Brokerage**. هوية «إيفاكون» تعتمد على الشعار المقدم من الشركة، وأسعار ووحدات ورسوم العقارات للتوضيح فقط وليست عروضًا حقيقية.

## الموجود داخل الموقع

- صفحة رئيسية حديثة عربية من اليمين للشمال (RTL)، ومتجاوبة مع التليفونات والتابلت والكمبيوتر.
- أقسام تعريف الشركة ورؤيتها ورسالتها وهدفها، وأسباب اختيارها وخطوات العمل.
- 6 وحدات تجريبية بأسعار ومساحات وغرف ومواقع، وصفحة منفصلة **لكل وحدة**.
- البحث والتصفية حسب المنطقة ونوع العقار والميزانية، مع فلترة سريعة حسب النوع.
- طلب تواصل/استشارة وتحديد الوحدة والمنطقة والميزانية وموعد معاينة مفضل.
- حفظ طلبات العملاء في السيرفر برقم مرجعي، ولوحة إدارة محمية تعرضها وتصدرها CSV.
- صفحة سياسة خصوصية نموذجية، وعناوين/وصف Meta مستقل لكل وحدة.
- صفر مكتبات JavaScript أو خادم خارجية مطلوبة للتشغيل؛ Node.js فقط. الصور ملفات SVG محلية توضيحية، والخط الإنجليزي/العربي المحسّن يتحمل من Google Fonts إذا الإنترنت متاح (مع خط احتياطي).

## التشغيل على Windows (PowerShell)

1. فك الضغط في أي فولدر، ثم افتح PowerShell بداخله.
2. تأكد من وجود **Node.js 20 أو أحدث** باستخدام `node -v`.
3. شغّل (استبدل كلمة المرور بمفتاح سري قوي):

```powershell
$env:ADMIN_USER="admin"
$env:ADMIN_PASSWORD="اكتب-هنا-كلمة-سر-قوية-وطويلة-جدا"
npm start
```

4. افتح في المتصفح:
   - الموقع: http://localhost:3000
   - إدارة الطلبات: http://localhost:3000/admin

هتظهر نافذة تطلب اسم المستخدم وكلمة السر عند فتح لوحة الإدارة. **كلمة السر مش موجودة في ملفات المشروع**؛ بتحددها من متغيرات البيئة.

## التشغيل على macOS أو Linux

```bash
ADMIN_USER=admin ADMIN_PASSWORD='Strong-Secure-Password-Change-Me' npm start
```

لو مش محدد كلمة مرور آمنة بطول 12 حرف على الأقل، لوحة الإدارة هتفضل مقفولة، لكن الموقع وفورم تسجيل الطلبات هيشتغلوا.

## تعديل الوحدات والأسعار

افتح `data/properties.json` وعدّل كل وحدة: `title` (الاسم)، `location` (المنطقة)، `type` (نوع العقار)، `price` (السعر بالجنيه)، `area`، `beds`، `baths`، `description`، `features`، `image`، و`slug` (الرابط الإنجليزي).

بعد التعديل، وأنت في مجلد المشروع:

```bash
python build.py
```

السكربت هيعيد بناء `index.html` وصفحات الوحدات تحت `properties/` بناءً على البيانات. **لو ضفت مناطق أو أنواع جديدة، أضفها كمان لقوائم الاختيار** الموجودة في `home.template.html` وراجع خيارات التحقق في `server.mjs`.

الصور الحالية محلية داخل `assets/property-1.svg` حتى `assets/property-6.svg` ومعاها `hero.svg`؛ تقدر تستبدلها بصور العقارات الحقيقية بعد التأكد من حقوق استخدامها. ضع ملفات JPG/WebP/PNG في `assets/` وغيّر قيمة `image` بالاسم الصحيح، مع تحديث الصور في الـHero وAlt Text.

## تعديل اسم الشركة والهوية

اسم «إيفاكون / EVACON» مستخدم بناءً على الشعار المرسل. لتحديثه، عدّله في:

- `home.template.html`، و`privacy.html` و`build.py` (للعنوان في صفحات الوحدات).
- `assets/evacon-logo.png` (الشعار الكامل) و`assets/evacon-mark.png` و`assets/evacon-favicon.png` للشعار.
- `assets/styles.css` لألوان EVACON (أحمر وأسود وأبيض) والخطوط.
- `admin.html` لاسم لوحة الإدارة.

بعد التعديل شغل `python build.py` مرة تانية.

## فين طلبات العملاء؟

بعد أول استفسار، بيتكوّن الملف `data/leads.json` على السيرفر. **الملف ده مش بيتعرض للزوار**؛ الطلبات تظهر فقط في `/admin` بعد تسجيل الدخول. تقدر تصدر CSV من اللوحة. الفورم لا يرسل بريدًا إلكترونيًا أو واتساب تلقائيًا؛ هو بيسجل الطلبات على السيرفر حاليًا. وفي حالة فشل الحفظ بيظهر للعميل خطأ واضح؛ مش نجاح وهمي.

بيانات الفورم تشمل: الاسم، الهاتف، نية الشراء/الاستثمار، الميزانية، المنطقة، توقيت الشراء، معاينة مفضلة (غير مؤكدة)، الوحدة المطلوبة، والرسالة. إرسال النموذج **لا يعني حجز العقار**.

**تنبيه إنتاج:** للحفاظ على الليدز في استضافة حقيقية، استخدم تخزينًا دائمًا بباك أب. المنصات اللي ملفاتها مؤقتة/Read-only مش مناسبة لتخزين JSON محلي، والأفضل نقل التخزين إلى قاعدة بيانات (PostgreSQL مثلًا) قبل التشغيل على نطاق واسع.

## الاستضافة الحقيقية

شغّل سيرفر Node على VPS أو منصة تدعم خدمات Node دائمة العمل، مع تخزين دائم لبيانات العملاء، واربط الدومين والـHTTPS. `server.mjs` يعمل كسيرفر التطبيق، وممكن توصل له Nginx أو Apache Reverse Proxy. لا تنشر لوحة الإدارة بدون HTTPS وكلمة مرور قوية، ويُفضّل إضافة نظام تسجيل دخول وجدار حماية/Rate Limiting على مستوى الاستضافة حسب حجم الاستخدام.

**لا ترفع ملف `data/leads.json` الحي إلى GitHub أو أي مستودع عام.** احتفظ به في تخزين خاص، وتأكد من آليات النسخ الاحتياطي والحذف وآلية الاستجابة لطلبات الخصوصية.

## الـSEO قبل إطلاق الموقع

النسخة التجريبية **ممنوعة من الفهرسة عمدًا** حتى لا تظهر وحدات أو أسعار وهمية في جوجل:

- صفحات HTML تحتوي `meta robots="noindex,follow"`.
- `robots.txt` يمنع كل البوتات من الزحف.

قبل الإطلاق، وبعد وضع بيانات الشركة والعقارات الحقيقية ومراجعة سياسة الخصوصية:

1. استبدل الديمو والصور والأسعار وأضف رقم الهاتف/البريد/العنوان الحقيقيين إن وُجدوا.
2. أزل علامات الـDemo، واكتب Meta Titles/Descriptions حقيقية.
3. غيّر `robots.txt` إلى السماح بالزحف مع منع مسارات الإدارة، وأزل `noindex` من الصفحات اللي عايز تفهرسها. **لازم الأمرين معًا**؛ إزالة أحدهما وحده غير كافية.
4. أنشئ `sitemap.xml` بالروابط النهائية من قائمة `data/site-routes.txt` بعد إضافة الدومين، وقدّمها في Google Search Console.
5. جهّز صفحات مناطق/خدمات بمحتوى فريد لو محتاج تستهدف كلمات زي «شقق للبيع في التجمع الخامس»، واستخدم صورًا ومواصفات أصلية.
6. اربط Google Analytics 4 / Search Console بعد ضبط سياسة خصوصية وإشعار تقنيات التتبع المناسبين.
7. استخدم Schema مناسب للـReal Estate Agent / الـProperty فقط ببيانات حقيقية ومحدثة.

## ملفات المشروع

| الملف / المجلد | وظيفته |
| --- | --- |
| `index.html` | الصفحة الرئيسية المولّدة |
| `home.template.html` | قالب الصفحة الرئيسية القابل للتعديل |
| `properties/*.html` | صفحات العقارات المولّدة |
| `assets/styles.css` | تصميم الموقع |
| `assets/app.js` | التفاعل، الفلترة، وإرسال الفورم |
| `assets/*.svg` | رسوم معمارية توضيحية واللوجو والأيقونات |
| `data/properties.json` | قائمة الوحدات وأسعارها |
| `server.mjs` | السيرفر وواجهة API للحفظ ولوحة الإدارة |
| `admin.html` | صفحة طلبات العملاء |
| `privacy.html` | صفحة سياسة الخصوصية النموذجية |
| `build.py` | توليد الصفحات من JSON |
| `make_assets.py` | إعادة توليد الرسوم التوضيحية، إذا احتجت |

**النسخة دي Prototype قابل للتشغيل، مش إطلاق إنتاج نهائي.** لازم تبديل البيانات التجريبية، ربط الاستضافة والدومين، واختبار الأمان والخصوصية قبل استقبال بيانات عملاء حقيقية.

## الهوية الرسمية المضافة

- الشعار الأصلي المقدم محفوظ بشفافيته في `assets/evacon-logo.png`.
- أيقونة الشعار مقصوصة فقط في `assets/evacon-mark.png` للـHeader وبعض الصفحات الداخلية، ويظهر الشعار الكامل في Footer الصفحة الرئيسية، و`assets/evacon-favicon.png` للمتصفح.
- اعتمدنا ألوان الشعار الأحمر والأسود والأبيض، واسم EVACON / إيفاكون، وشعاره المكتوب «ابتكر، اصنع الفرق» / «We Innovate to Make a Difference».
- اسم الشركة وشعارها هنا حقيقيان بناءً على الملف المرسل؛ **الوحدات والأسعار والموقع الجغرافي المفترض لا تزال تجريبية**.
